## O que ainda quero melhorar

Sou iniciante e sei que estes exercícios ainda têm pontos a evoluir. Deixo aqui o que já identifiquei, para acompanhar meu progresso:

- **Exercício das frutas:** os preços usados no código são inteiros (2, 3 e 4), diferentes dos do enunciado (R$ 1,85, R$ 2,30 e R$ 3,60), e o ",00" do resultado foi escrito à mão. Quero refazer com números decimais (`float`) e formatar o valor com duas casas.
- **Cálculo repetido:** em cada ramo do `if/elif` o cálculo e a mensagem se repetem. Quero fazer cada ramo apenas definir o preço e calcular uma única vez, depois da condição.
- **`EstruturasRep.py`:** a média das notas é recalculada dentro do laço a cada volta. O resultado final sai certo, mas o ideal é calcular uma vez só, depois do laço.
- **`For.py`:** a variável `media` do último bloco não guarda de fato uma média, e o arquivo ainda precisa de comentários explicando cada trecho.
- **Entradas inválidas:** se o usuário digitar texto no lugar de um número, os programas encerram com erro. Quero aprender tratamento de exceções (`try/except`).
- **Organização:** padronizar o nome dos arquivos (minúsculas, sem acento, nomes descritivos) e escrever mensagens de commit mais claras.
